<p>I've been on XDA since 2006 and remember when I actually had an O2 XDA IIi.</p>

<p>Like many here, I've custom ROM'd pretty much every WinMo and Android device I've owned, and have come to the conclusion that I hate extra bloat in stock ROMs, but I also hate when custom ROM builders stray too far from the device's stock look and feel.</p>

<p>I also absolutely hate the self-promotion some ROM builders love to indulge in with their custom builds, where they add a stupid logo, boot sound or some god awful theme to let the world know that 'I MADE THIS'.</p>

<p>Also I'd never ask for a donation unless I actually made something myself...that is, I opened up my favourite IDE and actually wrote some code...rather than just bundle some other poor devs real effort into my own new self-promoting heavily branded package.</p>

<p><strong>AND BREATHE.....</strong></p>

<p>Allow me to introduce my own first custom ROM.</p>

<p style="color: #f23a12;"><strong>Mostly Stock 1.0</strong></p>

<p><strong>Important things to note are...</strong></p>

<p>I made this for my own use, but figured that if someone else feels like I do, then maybe they'd like to use it as well. <strong>If you don't like this, use another ROM.</strong></p>

<p>I've been testing the core version of this ROM for a good few days now but this is an RC release and I'm new to this game so if you find any issues, please let me know and I'll try to fix them. I haven't found any myself.</p>

<p>This is not an extreme custom ROM that is so 'optimised' some things don't work properly.</p>

<p>This ROM is just a de-bloat (again not extreme as I find some Samsung apps useful), a zip align, with a custom kernel and modem.</p>

<br>

<p><strong>Ok, some features</strong></p>

<p><strong>* Choice of old launcher or new Android KitKat 4.4 launcher<br>
* Includes the brilliant Boeffla Kernel 5.2. Please get Boeffla Config V2 from Play Store for full control.<br>
* Features Galley 2013 (but I'm not sure if I like this so may downgrade in a future release).<br>
* Features modem XXUGMJ9 as I found boot issues with older modems<br>
* No stupid custom logos<br>
* No pleas for money<br>
* Samsung boot sound...I don't think this is a bad thing</strong></p>

<p><strong>Things to be added</strong></p>

<p>* Removal of stupid EU volume warning<br>
* Placing some of the included apps (like the launcher) into the data folder so that they can be un-installed if they are not required</p>

<p>Please install using Team Win Recovery Project. It may work with ClockworkMod recovery too, but I've not tested this.</p>
